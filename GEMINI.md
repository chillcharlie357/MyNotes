# GEMINI.md

## Directory Overview

This directory is a personal knowledge base and collection of notes, managed using the Obsidian note-taking application. The content primarily consists of academic notes organized by year and course subject, suggesting it belongs to a student.

The notes are written in Markdown and often include YAML frontmatter for metadata such as tags, categories, and creation/modification dates.

The directory is structured as an Obsidian Vault, with the `.obsidian` directory containing configurations for plugins, themes, and workspaces.

## Key Files

*   `README.md`: A simple placeholder file for the vault.
*   `.obsidian/`: This directory contains all the configuration for the Obsidian vault.
    *   `.obsidian/community-plugins.json`: Lists the installed community plugins, which provide a good overview of the user's workflow. The user has installed plugins for features like admonitions, tables, dataview, excalidraw, git integration, and more.
*   `/2022Fall`, `/2023Spring`, etc.: Directories for different academic semesters, containing notes for the courses taken in those semesters.

## Usage

This directory is intended to be used as an [Obsidian](https://obsidian.md/) vault. To use it, open the directory as a vault in the Obsidian application.

The notes are in Markdown format and can be edited with any text editor. However, to take full advantage of the features and plugins, it is recommended to use Obsidian.

The notes are organized in a hierarchical structure based on the academic year and course. The user also seems to use a variety of plugins to enhance their note-taking, including:

*   **Dataview:** For querying and displaying data from notes.
*   **Excalidraw:** For embedding drawings and diagrams in notes.
*   **Obsidian Git:** for versioning and syncing notes with a Git repository.
*   **Pandoc:** For converting notes to other formats.
